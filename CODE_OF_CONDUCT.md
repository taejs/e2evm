# Community conduct

E2EVM welcomes people with different backgrounds, experience levels, and perspectives. Treat contributors and users with respect.

- Discuss ideas and code without personal attacks.
- Explain disagreements with concrete examples and allow others time to respond.
- Respect privacy, consent, and intellectual property.
- Do not harass, threaten, discriminate, post sexualized material, or repeatedly disrupt discussions.
- Do not publish another person's private information or credentials.

These expectations apply in repository issues, pull requests, discussions, and other spaces maintained for this project. Maintainers may edit or remove harmful content, close disruptive conversations, or restrict participation. Enforcement should consider the context and severity of the behavior.

For public incidents, flag the content through GitHub's reporting tools or contact the maintainer in the affected thread if doing so is safe. To arrange a private report, open an issue requesting a private contact channel without identifying the affected person or disclosing sensitive details. Security vulnerabilities follow the separate [security policy](SECURITY.md).
